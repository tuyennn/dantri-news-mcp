# Dantri News MCP Server (Python)

## Run from GitHub

```bash
npx -y github:tuyennn/dantri-news-mcp
```

## MCPHub Config

```json
{
  "mcpServers": {
    "dantri-news": {
      "command": "npx",
      "args": [
        "-y",
        "github:tuyennn/dantri-news-mcp"
      ]
    }
  }
}
```

## Requirements

- Node.js
- Python 3
- python3-venv installed
